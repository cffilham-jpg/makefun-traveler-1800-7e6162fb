# One Sentence for a Traveler from 1800

A single sentence that explains the modern internet to a time traveler who
has just stepped out of the year 1800 — built only from words and things a
person from 1800 already knows: a library, a post office, wires, letters,
and pages.

> Think of a library and a post office joined by wires, where a letter reaches the other side of the world in a blink and any page can be read the moment you ask for it.

`main.py` (Python 3.13, standard library only) writes that sentence to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `out`),
with no trailing newline, then validates the output: a single line, 1–200
characters, no leading or trailing whitespace.
